# task-09: Descoberta dos demais nichos e lista final

**Fase:** Descoberta · **Depende de:** task-08 · **Status:** ⬜

## Objetivo
Montar o `config/concorrentes.json` final com todos os nichos.

## Passos
1. Rodar a descoberta, um nicho de cada vez: saúde ocupacional, civil, elétrica, incêndio e ambiental. Confirmar o custo antes de cada um.
2. O usuário aprova os candidatos de cada nicho.
3. Gravar `config/concorrentes.json` com `handle`, `rede`, `nicho`, `seguidores` e `ativo: true/false`.
4. Incluir `grupoecasi` com `"baseline": true`.

## Critério de pronto
