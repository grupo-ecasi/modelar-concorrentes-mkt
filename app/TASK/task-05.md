# task-05: Estrutura de pastas e CLAUDE.md do projeto

**Fase:** Base · **Depende de:** — · **Status:** ⬜

## Objetivo
Criar o esqueleto do projeto e um `CLAUDE.md` com as regras que todo agente deve seguir.

## Passos
1. Criar as pastas: `.claude/agents/`, `.claude/skills/`, `config/`, `scripts/`, `data/raw/`, `relatorios/`, `docs/`.
2. Escrever o `CLAUDE.md` com:
   - o que é o Grupo Ecasi, os nichos e o objetivo (viralizar no Instagram/TikTok)
   - as regras de custo (estimar e confirmar antes de rodar a Apify)
   - as regras de LGPD (sem dados de quem comenta)
   - a convenção de idioma
   - o mapa de pastas
3. Criar um `.gitignore` que ignora `data/raw/` (e, opcionalmente, rodar `git init`).
