# task-08: Descoberta piloto no nicho SST

**Fase:** Descoberta · **Depende de:** task-07 · **Status:** ⬜

## Objetivo
Rodar a descoberta só no nicho SST, para validar a qualidade e o custo.

## Passos
1. Rodar `descobrir-concorrentes` com o nicho `sst`.
2. Revisar a tabela de candidatos com o usuário.
3. Anotar o custo real gasto na Apify.
4. Ajustar filtros e hashtags se vierem perfis irrelevantes (lojas de EPI, perfis pessoais etc.).

## Critério de pronto
- [ ] Lista de candidatos de SST aprovada pelo usuário.
- [ ] Custo real anotado neste arquivo.
